Laboratório de Voz

Arraste os controles, ouça a frase real do jogo e cole o resultado na tabela TONS de JS/narration.js. As vozes listadas são as que existem nesta máquina — a criança vai ouvir a voz da máquina dela.

Voz

O jogo escolhe sozinho pela ordem de qualidade. Aqui você força uma para comparar.

    Como usar

    1. Ouça cada tom como está.
    2. Ajuste velocidade e altura até agradar.
    3. Copie o código e substitua a tabela TONS.
    4. Teste no jogo com Ctrl + F5.

    Cole isto no lugar da tabela TONS

    
  
    

  
    
    A Web Speech API usa a voz instalada no aparelho, então o mesmo rate soa um pouco diferente em cada máquina — ajuste pelo que for aceitável no pior caso, que costuma ser o Chromebook do laboratório. Se nenhuma voz em português aparecer na lista, o navegador vai ler com sotaque da voz padrão do sistema: nesse caso vale instalar a voz pt-BR no sistema operacional, não mexer nestes números.
